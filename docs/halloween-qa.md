# Проверка Halloween edition

27 октября 2026. Локальная production-сборка, Chromium.

- `npm run build` → `npm test`: 10 из 10 проверок пройдены.
- RU и EN на ширинах 320, 390, 768, 980, 1024, 1366, 1440 px:
  горизонтального переполнения заголовков и контролов нет; изображения загружаются.
- EN: кириллицы в видимом тексте нет.
- Диалог возможностей закрывается Escape, фокус возвращается к вызвавшей кнопке
  на desktop и mobile. Исправлен существовавший возврат к скрытой desktop-кнопке.
- Переход «Войти» из шапки фокусирует Email, открытие восстановления работает.
- Бегущая строка: кнопки паузы/продолжения работают, после продолжения
  animation-play-state=running; при prefers-reduced-motion animation-name=none.
- Ошибок в консоли при проверке production-preview нет.
- Скриншоты desktop RU, mobile EN и 320 px EN визуально просмотрены.
- Логотип, Lora / Source Sans 3 и настоящий Electron capture сохранены.
  По последующему запросу пользователя реализован чёрный вариант
  по самому onda-andar.ru: тонкая белая рамка, белый знак, красные черепа,
  локальный Source Code Pro. Светлый коллаж предыдущей итерации удалён.
- Авторизация проверена существующим тестом SDK против отдельного localhost fixture.
  В production Supabase тестовые регистрации и отправка писем не выполнялись.
- Существующие тесты ссылок релизов и кэша GitHub прошли.
- В браузере на 320 px проверен раскрытый выбор платформ и процессора Mac:
  для Intel показано отсутствие сборки, ARM64 ведёт к существующему dmg v0.0.8.
  Переполнения полей и кнопок нет. Счётчик GitHub перенесён в footer.
- Облачные настройки, email templates и PAGES_ENABLED не изменялись.

Vite сообщает о размере существующего основного JS chunk больше 500 КБ;
новых JS-зависимостей не добавлено, добавлен только локальный пакет шрифта.

`halloween-mobile-en.png`, `halloween-320-en.jpg`.
