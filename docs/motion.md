# Движение

Использованы принципы поэтапного появления из [Motion stagger](https://motion.dev/docs/stagger) и [easing](https://motion.dev/docs/easing-functions), реализованные небольшими CSS-анимациями без библиотеки. [MDN animation timing](https://developer.mozilla.org/en-US/docs/Web/CSS/animation-timing-function) — справочник кривых.

- Заголовок, пояснение, загрузка и реальный скрин появляются с небольшим сдвигом и задержкой 80–220 мс.
- Формы входа/регистрации меняются без ухода со страницы. Ошибки не очищают поля.
- Кнопки реагируют на наведение и нажатие. Панель возможностей выезжает справа.
- Поддерживается prefers-reduced-motion; не анимируются текстовые символы, выделение и ввод.
- Счётчик GitHub обновляется каждые 10 минут и при возвращении на вкладку. Кэш на 5 минут ограничивает запросы; закрытая вкладка не опрашивает API.
