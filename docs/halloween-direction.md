## Итоговое направление: сам сайт onda-andar.ru

По последующему прямому уточнению пользователя референсом стал
[onda-andar.ru](https://onda-andar.ru/), а не общее настроение канала.
Ветка сохранена. Отказ от светлого фона и моховой цветовой схемы следует
этому более позднему запросу пользователя.

Просмотрены desktop и mobile самого референса: сплошной чёрный фон,
маленький белый знак по центру, бегущая строка с красными черепами,
тонкая белая рамка основного блока, моноширинная типографика,
центрированное медиа ниже и короткий footer. На момент просмотра
каталог референса отображает «Ничего не найдено»; это состояние
на Hopdock не переносится.

Hopdock получает ту же визуальную структуру. В рамке остаются
заголовок и рабочее скачивание. Под ней — настоящий Electron capture.
Возможности и аккаунт оформлены чёрными блоками с тонкими линиями.
Фирменный знак сохранён, отображается белым. Lora остаётся в wordmark,
Source Sans 3 — в пояснениях и формах. Source Code Pro, как у референса,
локально подключён для моноширинной типографики. Черепа — простой собственный SVG.
Генерированная иллюстрация предыдущего варианта удалена из итогового сайта.
Личные фотографии, видео и логотип артиста не копируются.

У бегущей строки есть кнопка паузы, остановка при наведении/фокусе
и статичное состояние при prefers-reduced-motion.

Функциональные компоненты скачивания и авторизации остаются прежними.
Публикация и изменение облачной конфигурации не входят в эту ветку.
