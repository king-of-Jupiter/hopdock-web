# Настоящий скриншот Hopdock

`public/assets/terminal-preview.png` снят с production Electron Hopdock через `BrowserWindow.webContents.capturePage()`, размер 1440 × 580. Это настоящая отрисовка приложения, а не сгенерированный интерфейс. После захвата изображение не редактируется.

Использована существующая сборка `hopdock/apps/desktop/out`, тёмная тема и отдельный временный профиль `hopdock-web-capture-*` в системном Temp. Рабочая библиотека пользователя, исходники Hopdock и старые скриншоты не изменялись. После съёмки закрывается только окно запущенного для съёмки экземпляра.

SSH-соединение, авторизация паролем, PTY, ввод команд и resize настоящие. Сервер запускается только на `127.0.0.1` со случайным портом. Вывод `uname -a`, `df -h` и `uptime` — безопасные детерминированные ответы fixture, а не измерения настоящего Ubuntu-сервера. Примерные сниппеты находятся только в изолированном профиле. Облачная синхронизация не подключена; статус приложения это отражает.

## Воспроизведение

Нужна соседняя папка `../hopdock` с уже собранным production `apps/desktop/out` и установленными зависимостями Electron, Playwright и ssh2. Скрипт не пересобирает Hopdock.

```powershell
cd C:\Users\freshh\Desktop\hopdock-web
node scripts/capture-terminal.mjs
```

Для другого расположения Hopdock задать `HOPDOCK_SOURCE`. `capture-entry.cjs` требует явного отдельного профиля и не использует обычный `userData`. Скрипт на время показывает своё Electron-окно и после съёмки закрывает его.

Метод, дата, версия, хеш изображения, размеры и подтверждение SSH-операций сохраняются в `docs/terminal-capture.json`.
