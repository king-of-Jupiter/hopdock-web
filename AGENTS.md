# Hopdock Web

Сайт живёт в отдельном репозитории, не менять исходники и рабочий профиль соседнего Hopdock.

- Сохранять выбранный макет docs/reference.png: светлая левая часть, тёмная регистрация справа, Lora / Source Sans 3 и утверждённый знак.
- Поддерживать русский и английский текст, клавиатуру, prefers-reduced-motion и мобильную раскладку.
- Превью приложения public/assets/terminal-preview.png — настоящий Electron capture. Не заменять генерацией; источник описан в docs/terminal-capture.md.
- Использовать только публичный Supabase ключ в браузере. Не хранить SMTP, service_role и management token в Git.
- Не создавать тестовые аккаунты в рабочем Supabase. Проверки авторизации — отдельный localhost fixture, реальные production проверки только чтение или отклонённый вход в несуществующий аккаунт.
- Скачивать только существующие файлы релиза king-of-Jupiter/hopdock. На Mac не угадывать процессор по MacIntel user agent. Для недоступной сборки давать страницу релизов.
- Счётчик звёзд не подделывать: при недоступном API показывать кэш или тире.
- Публикация включается отдельно через PAGES_ENABLED. Перед публикацией завершить тесты и design QA.
- Сначала npm run build, затем npm test: тест упаковки проверяет готовые dist файлы. Письма: npm run emails:build. Не применять письма к облаку без задачи настройки; npm run emails:apply -- --dry-run не изменяет проект.
