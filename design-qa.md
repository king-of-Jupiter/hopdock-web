## Обязательные поверхности

- Fonts/typography: локальные Lora 400/600, Source Sans 3 400/600. Сохранены двухстрочный заголовок, serif branding и иерархия; переносы английской версии проверены. Терминал — текст настоящего приложения внутри изображения.
- Spacing/layout: светлая/тёмная пропорция 65/35, положение заголовка, регистрации и кнопки сохраняют макет. Правой форме не добавлены карточка или рамка. Дополнительная маленькая ссылка платформ и переключатель языка — необходимые новые функции. На телефоне блоки идут последовательно.
- Colors/tokens: фарфор #faf9f5, тёмный #262624, поля #30302d, акцент #a6b58a, загрузка #596345; читаемые foreground и focus rings в обеих поверхностях.
- Image quality/assets: утверждённый существующий SVG-знак, библиотечные иконки Phosphor. По прямому уточнению пользователя вместо генерации поставлен настоящий Electron capture 1440 × 580, без редактирования изображения; происхождение docs/terminal-capture.md. Этот скрин намеренно отличается от нарисованного UI в мокапе и честно показывает sync not configured.
- Copy/content: весь интерфейс переведён RU/EN; ошибки также переведены. Пустые пароли в рабочей форме не заполнены декоративными точками из макета. Не обещаются отсутствующая Intel-сборка, мобильное приложение или настроенная cloud синхронизация.

## Взаимодействия и проверка

- RU/EN, подписи форм, вкладка входа, восстановление пароля, фокус на заголовке, password mismatch без потери введённого email/пароля.
- Регистрация через настоящий SDK в отдельный локальный Auth fixture; success state, 60-секундный cooldown повторного письма, ошибка неверного входа, сохранение полей, восстановление, callback в форму нового пароля, logout.
- Сохранение нового пароля, вход с ним и session lifecycle дополнительно проверены тестом настоящего SDK на отдельном localhost fixture. Это не проверка доставки SMTP или регистрации в облаке.
- Правый dialog возможностей: открытие, Escape и возврат фокуса. Защита от закрытия при drag-selection заложена pointerdown/pointerup.
- Реальные API GitHub: показаны 0 звёзд, правильные Windows/dmg ссылки. Во время проверки сайт самостоятельно получил новый v0.0.8 вместо первоначального v0.0.7. Кэш, обновление звёзд и rate-limit fallback проверены тестом.
- Browser console errors: 0 на рабочем preview. Преднамеренный отказ fixture входа — HTTP 400, обработанный интерфейсом.
- CSS prefers-reduced-motion отключает все анимации/переходы; override ОС в браузере не переключался. Основная анимация opacity/transform не перехватывает мышь или клавиатуру.
- Письма confirmation RU и recovery EN визуально просмотрены в браузере: docs/email-confirmation-ru.jpg, docs/email-recovery-en.jpg. 13 шаблонов проверены на правильные placeholders. Рендер Outlook/Gmail и реальная SMTP-доставка не проверялись.
- npm test: 10/10 passed. Production build passed.
